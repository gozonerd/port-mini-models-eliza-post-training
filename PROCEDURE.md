The engine is a Python port of the 1966 script written by the seat and verified against Anthony Hay's implementation (CC0) until the two disagree on zero replies; its replies are Weizenbaum's templates, not the seat's text. 9. **Engine written and verified** (2026-10-15, evening). `eliza/engine.py` is a port of the 1966 interpreter following Hay's C++ (commit `4ac38e6`, CC0, kept under `third-party/anthay-ELIZA/` with hashes in `SOURCES.tsv`): keystack and NEWKEY, the three delimiters (comma, period, BUT), the LIMIT counter gating memory recall, the mid-square HASH on the Hollerith encoding of the last chunk of the last word, the four built-in NOMACH messages, the YMATCH-style matcher, and per-decomposition-rule cycling of reassembly rules. Verification: `tests/test_cacm.py` reproduces the CACM article's conversation reply for reply; `tools/verify_against_hay.py` diffs the port against Hay's compiled binary on generated stress conversations (verification-only sentences built from the script's own words; never training data): seed 20261015, 400 conversations, 2,887 turns, 0 mismatches; seed 7, 300 conversations, 0 mismatches. Hay's binary is compiled locally with g++ and is not committed.
10. **Data generated** (2026-10-15, evening). `tools/generate_data.py`, seed 20261015: 3000 / 400 / 400 conversations (train / dev / test), about 21,000 / 2,800 / 2,900 turns, split by conversation, filler vocabulary partitioned three ways so held-out sentences carry unseen filler words. Every plain-reply pattern of the script fires in every split (45 of 45; the other 10 patterns are special-only). Ten percent of conversations are cycle drills. Both framings emitted per split; `data/manifest.json` records the seed and the SHA-256 of the script, the word list, the generator, the engine and every output file. Train files are regenerated, not committed. Sources: the 1966 script and SCOWL only.
11. **Floor protocol fixed before measurement** (2026-10-15, evening). `FLOOR_PROTOCOL.md` pins the seven base checkpoints by revision hash, the test split by manifest hash, the prompt format (`transcript-v1`: greeting line, alternating user and reply lines), greedy decoding with the reply taken as the first non-empty generated line, and the two scoring rules. `tools/measure_floor.py` implements it and writes one row per (model, framing) to `runs/runs.tsv` with per-item files beside it. Smoke-tested on the cached SmolLM2-360M-Instruct (24 items per framing; not a floor number; the instruct model is not in the ladder). The base-model weights are downloaded by Krystal Martinez, at the pinned revisions, before the floor is run.
