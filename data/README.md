# data/ — Wave 01 training and evaluation sets

Generated by `tools/eliza_generate_data.py` (seed 20261015). Deterministic: the same seed, generator and
engine reproduce every byte; `manifest.json` carries the SHA-256 of each file for checking.

**Where every token comes from.** User sentences are built from the 1966 script's decomposition
patterns, with slots filled from the script's own word lists and from the SCOWL word list (Debian
`wamerican`, permissive licence; path and hash in the manifest). Replies are the script's templates,
produced by the verified engine. No language model wrote any of it (ruling K60).

**Files.** `<split>.conversations.jsonl` is the canonical record: one conversation per line, each turn
with its user sentence, the engine's reply, the framing-A allowed set, and a trace (keyword, pattern
index, template index = cycle position, kind: reply / none / memory / nomatch, LIMIT). `<split>.A.jsonl`
is framing A (single exchange; `allowed` lists every plain template of the pattern that fired,
instantiated). `<split>.B.jsonl` is framing B (`history` of earlier exchanges; the exact next `reply`).
`coverage.tsv` counts turns per (split, kind, keyword, pattern, cycle position).

**Splits** are by conversation (3000 / 400 / 400). The filler vocabulary is partitioned three ways, so
dev and test sentences contain filler words that never appear in training. The ten patterns that never
fire as a plain reply are the ones whose templates are all special (NEWKEY, =KEY, PRE); they still
occur as the route to other replies. The train files are not committed (26 MB; regenerate with the
command in the generator's docstring); dev and test are.

**Known artificiality.** Filler words are random dictionary words, so sentences read like
"Malted boink airdrop I am midwived grandson derisive". The task is the rule mapping and the cycle,
which this exercises; it is not English fluency. Ten percent of conversations are cycle drills that
fire one pattern more times than it has templates, so every cycle position and the wrap-around occur.
